THIS IS A WAVE SIMULATION

The pictures are in
the interference.

A phase plate delays different parts of a light wave. Those waves overlap: reinforcing in some places, cancelling in others. An optimizer finds one pattern of delays that creates two images at different depths.

Moving the card runs a new wave-propagation calculation in Three.js WebGPU. The phase pattern stays fixed. The display never swaps in a drawing.

Capturing checks the computed light image, rather than whether you reached a preset position. You can write your own two images into a new seal.

This is established computer-generated holography in a browser interaction, not a new optical principle. The model uses monochromatic coherent light, scalar angular-spectrum propagation, and a finite sampled phase plate. The scene magnifies transverse dimensions for readability. Faint points visualize sampled wave intensity as scattering; they are not a volumetric light-transport simulation. This is not a fabrication or laser setup guide.

Drag the glass, use the slider, scroll over it, or use the arrow keys. The scene renders only when something changes.
